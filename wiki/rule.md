---

## Ветки

Каждая задача выполняется в отдельной ветке.

Формат:

```
<type>/#<номер>-short-description
```

Типы:

* `feature` — новая функциональность
* `fix` — баг
* `refactor` — рефакторинг
* `docs` — документация
* `test` — тесты

Пример:

```
feature/#12-add-search
fix/#8-login-error
```

Прямые коммиты в `main` запрещены.

---

## Коммиты

Формат:

```
[feature/#12] - добавлен поиск по тегам
```

Где:

* `feature` — тип
* `#12` — номер Issue

Один коммит — одна логическая правка.
Сообщения должны быть осмысленными.

## Pull Request

* Работа через PR.
* Перед мержем — минимум 1 одобрение.
